# 말문 (malmun) — 첫 한마디를 조금 쉽게

> 첫 한마디가 어려운 사람을 위한 **무료 커뮤니케이션 지원 웹 서비스**.
> 사람을 바꾸는 대신, 말을 시작하는 순간의 작은 장벽을 낮춥니다.

**🔗 라이브: https://malmun-three.vercel.app**

주말에 개인적으로 기획·제작한 사이드 프로젝트입니다. 내향적인 성향은 고쳐야 할 문제가 아니라는 생각에서 출발해, "사람을 바꾸는 대신 환경의 작은 장벽을 낮출 수는 없을까?"라는 질문 하나로 만들었습니다.

## 왜 만들었나

새로운 학교·직장·교육·동아리처럼 낯선 환경에서는 누구에게나 관계 형성이 필요합니다. 하지만 **먼저 말을 거는 능력과 속도에는 분명한 개인차**가 있고, 그건 성격의 결함이 아니라 그저 진입장벽일 뿐입니다.

말문은 "말을 잘하게" 만들려 하지 않습니다. 대신 **첫 한마디를 꺼내는 그 순간의 부담만** 조금 덜어주는 것을 목표로 합니다.

## 운영 원칙

- **무료** — 핵심 기능은 누구나 부담 없이
- **광고 없음**
- **로그인 없음** — 계정도, 가입도 필요 없음
- **최소 개인정보** — 입력한 내용은 서버에 저장하지 않고, 브라우저(localStorage)에만 남음

## 기능

| 도구 | 설명 |
|------|------|
| **첫 한마디 도우미** 🤖 | 상황(점심시간·첫 출근·모임 등)과 한 줄 맥락을 주면 **AI가 자연스러운 첫 한마디 3개 + 이어갈 질문 + 피할 것**을 제안 |
| **소셜 배터리** 🔋🤖 | 오늘의 사교 에너지를 누르면, **배터리가 1인칭으로 건네는 한마디 + 맞춤 처방**을 AI가 생성 (방전인 날엔 "인사만 해도 충분해요" 같은 허락으로) |
| **대화 소재 자판기** | 분위기별로 가볍게 시작할 대화 소재 추천 |
| **오늘의 용기 1cm** | 오늘 실제로 해볼 수 있는 아주 작은 행동 하나 제안 |
| **작은 성장 기록** | "먼저 인사했다" 같은 작은 변화를 브라우저에만 기록 |

## 기술 스택

- **프론트엔드**: 순수 HTML / CSS / JavaScript (프레임워크·빌드 과정 없음)
- **호스팅 / 배포**: Vercel (GitHub 연동 자동 배포)
- **AI**: [Claude API](https://www.anthropic.com/) — `claude-haiku-4-5` + 구조화 출력(structured outputs)
- **백엔드**: Vercel 서버리스 함수 1개 (`api/generate.js`) — 의존성 없이 Node.js 런타임의 `fetch`만 사용
- **데이터**: 별도 DB 없음. 사용자 기록은 `localStorage`에만 저장

## AI 연동 구조

정적 사이트에 AI를 붙이면서도 **API 키를 브라우저에 노출하지 않는 것**이 핵심 과제였습니다.

```
브라우저 (tools.js)
   │  POST /api/generate  { mode, situation, context, energy }
   ▼
Vercel 서버리스 함수 (api/generate.js)   ← API 키는 환경변수에만 (코드/깃에 없음)
   │  mode별 프롬프트 + JSON 스키마 구성
   ▼
Claude API (Haiku 4.5, 구조화 출력)
   │  { openers, followUp, avoid }  또는  { voice, tip }
   ▼
브라우저에서 고정 골격으로 렌더 · 실패 시 정적 문장으로 폴백
```

- **엔드포인트 하나로 통일**: `mode` 파라미터(`starter` / `battery`)로 분기해, 도구가 늘어도 함수는 하나만 유지
- **구조화 출력**: `output_config.format`(JSON 스키마)으로 응답 형태를 강제 → UI가 항상 같은 골격으로 렌더
- **우아한 폴백**: API 실패·키 미설정 시 정적 문장으로 자동 대체되어 사이트가 절대 깨지지 않음
- **키 보안**: `ANTHROPIC_API_KEY`는 Vercel 환경변수에만 존재. 로컬은 `.env`(`.gitignore` 처리), 저장소·번들 어디에도 키가 없음

설계 상세: [`docs/ai-first-message-flow.md`](docs/ai-first-message-flow.md)

## 로컬에서 실행 / 직접 배포하기

정적 파일이라 별도 빌드가 필요 없습니다.

**정적 부분만 미리보기**: 아무 정적 서버로 폴더를 열면 됩니다.
```bash
npx serve .
```

**AI 기능까지 포함해 배포**: [Vercel](https://vercel.com)에 이 저장소를 연결한 뒤, 프로젝트 환경변수에 키를 추가합니다.
```
ANTHROPIC_API_KEY = <your Anthropic API key>
```
> ⚠️ 키는 절대 코드에 넣거나 커밋하지 마세요. 로컬 개발용으로는 `.env`에 두면 되고, 이 파일은 `.gitignore`에 포함되어 있습니다.
